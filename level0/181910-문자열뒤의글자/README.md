# 문자열 뒤의 글자

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/181910
- 난이도: Lv.0

## 왜 어려웠나 (처음에 놓쳤던 부분)
- 문자열을 "뒤에서부터 n개" 잘라내야 하는 상황에서, 처음엔 이 방식을 바로 떠올리지 못함
  → 문자열도 리스트처럼 음수 인덱스 슬라이싱이 가능하다는 걸 활용해야 했음

## 배운 점
- 뒤에서부터 n개를 가져오고 싶을 땐 `문자열[-n:]`
  - `-n`은 "뒤에서 n번째"라는 뜻이고, 그 뒤에 `:`만 붙이면 거기서부터 끝까지 전부 가져옴
  - 예: `"hello"[-2:]` → `"lo"` (뒤에서 2글자)
- 반대로 "뒤에서 n개를 제외한 나머지"를 가져오고 싶으면 `문자열[:-n]`
  - 예: `"hello"[:-2]` → `"hel"` (뒤에서 2글자를 뺀 나머지)
