# 첫번째로 나오는 음수 찾

- 링크: (https://school.programmers.co.kr/learn/courses/30/lessons/181896)
- 난이도: Lv.0

## 왜 어려웠나 (헷갈렸던 부분)
- `num_list[i-1]`처럼 인덱스를 임의로 밀어서 접근함
  → i가 0일 때 `num_list[i-1]`은 `num_list[-1]`이 되는데, 파이썬에서 `-1`은 에러가 아니라 **맨 뒤 원소**를 가리킴. 그래서 의도한 위치가 아니라 엉뚱한 값을 봄
- 조건을 만족해도 멈추지 않고 반복문을 끝까지 돌림
  → `break`가 없어서 `answer`가 매 반복마다 계속 덮어써지고, 결과적으로 "마지막 조건 결과"만 최종 답으로 남는 구조가 됨
- `len(리스트)`와 인덱스 범위를 헷갈림
  → `len(num_list)`는 원소 "개수" 그 자체 (예: 5개면 5), 인덱스는 항상 0부터 시작하므로 마지막 인덱스는 `len(num_list) - 1`
  → `range(len(num_list))`를 쓰면 0부터 len-1까지 정확히 인덱스 범위와 일치해서 안전하게 순회 가능

## 배운 점
- `num_list[i]`는 인덱스 i번째 값을 가져오는 정상적인 방법 — `range(len(num_list))`와 짝을 이루면 항상 안전
- `num_list[i-1]`, `num_list[i+1]`처럼 인덱스를 임의로 미는 건 항상 조심
  - `i-1`이 음수가 되면 조용히 "맨 뒤 원소"를 가리켜버림 (에러가 안 나서 더 위험)
  - `i+1`이 범위를 넘으면 `IndexError` 발생
- "조건 만족하면 즉시 멈추고 결과 반환"이 필요한 로직엔 반드시 `break` (또는 그 자리에서 `return`)
- 값(`num`)과 인덱스(`i`)는 다른 개념 — 값 자체엔 `.index()` 같은 위치 찾는 메서드를 쓸 수 없고, `리스트.index(값)` 형태로 리스트 쪽에서 찾아야 함
