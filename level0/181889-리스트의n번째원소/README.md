# 리스트의 n번째 원소

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/181889
- 난이도: Lv.0

## 왜 어려웠나 (처음에 놓쳤던 부분)
- 슬라이싱 개념을 떠올리지 못하고, 무조건 `for i in range()`로 하나씩 접근하려고만 함
  → num_list의 "첫 번째 원소부터 n번째까지"라는 조건 자체가 슬라이싱으로 바로 표현 가능하다는 걸 못 봄
- 인덱스 계산 실수: "n번째 원소"를 인덱스로 쓸 때 `[n+1]`이라고 착각함
  → 첫 번째 원소는 인덱스 `[0]`이므로, n번째 원소는 인덱스 `[n-1]`, 슬라이싱으로 "첫 번째부터 n번째까지"는 `num_list[0:n]` (또는 `num_list[:n]`)이 맞음

## 배운 점
- "처음 n개", "앞에서부터 n번째까지" 같은 조건은 반복문보다 슬라이싱(`리스트[:n]`)으로 훨씬 간단하게 표현됨
- 인덱스는 0부터 시작하므로, "n번째"라는 말이 나오면 항상 실제 인덱스는 n-1이라는 걸 먼저 확인하기
- 슬라이싱 `[:n]`은 인덱스 0부터 n-1까지를 포함 (n번째 값 직전까지), 그래서 "1번째부터 n번째까지 총 n개"를 가져올 때 `[0:n]`이 정확히 맞아떨어짐
