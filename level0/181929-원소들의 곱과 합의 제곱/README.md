# 원소들의 곱과 합의 제곱
- 링크 : https://school.programmers.co.kr/learn/courses/30/lessons/181929
  
## 왜 어려웠나 (처음에 놓쳤던 부분)
- 리스트 원소를 누적해서 곱하거나 더하는 방법이 순간 기억이 안 남
  - `num = num + 1`처럼 잘못된 방향으로 생각했었음 (이건 그냥 num에 1을 더하는 것일 뿐, 누적 합/곱이 아님)
  - 올바른 패턴: 반복문 밖에서 `total = 1`(곱셈용) 또는 `total = 0`(덧셈용) 초기값을 만들어두고, 반복문 안에서 `total = total * num` 또는 `total = total + num`으로 매번 갱신해야 함

## 배운 점
- 누적 계산(합/곱)은 "반복문 밖 초기값" + "반복문 안 -> total = total 연산 num" 조합으로 만든다
- 곱셈 누적의 초기값은 반드시 1 (0으로 하면 전부 0이 되어버림), 덧셈 누적의 초기값은 0
