# 수 조작하기 1
- 링크 : https://school.programmers.co.kr/learn/courses/30/lessons/181926

## 왜 어려웠나 (처음에 놓쳤던 부분)
- 문자열도 `len(문자열)`로 길이를 구할 수 있다는 걸 놓침
- 문자열도 인덱싱(`문자열[i]`)이 가능하다는 걸 놓침
- control 문자열 길이만큼 반복하면서, 각 `[i]` 인덱스 값이 w/s/d/a 중 뭔지 확인할 때 **elif가 아니라 if로 각각 따로 조건을 걸어야 한다**는 걸 놓침

## 배운 점
- 파이썬에서는 문자열도 리스트처럼 `len()`, 인덱싱(`[i]`), 슬라이싱이 다 됨
- 여러 조건을 "각각 독립적으로" 확인해야 할 땐 elif로 묶지 말고 if를 따로따로 써야 함
  (elif는 하나 걸리면 나머지를 검사 안 하므로, 매 반복마다 매번 4개 조건을 다 확인해야 하는 상황엔 부적합)
