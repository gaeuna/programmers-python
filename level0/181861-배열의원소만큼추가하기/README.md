# 배열의 원소만큼 추가하기

- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/181861
- 난이도: Lv.0

## 왜 어려웠나
- 문제 지문 자체를 처음엔 이해 못 함. 뭘 요구하는 건지 감이 안 와서 일단 코드로 시도해보면서 감을 잡음
- 결과적으로는 한 번에 통과했지만, "이해하고 짠 코드"라기보다 "짜다 보니 맞았다"에 가까웠음

## 다시 봤을 때 이해한 로직
- `arr[i]`가 0이 아닌 값일 때만 (`if arr[i]:` → 0은 False로 취급되어 걸러짐)
- 그 값(`arr[i]`)만큼 반복해서, 그 값 자체를 answer에 그 횟수만큼 추가
- 즉 "각 숫자를 그 숫자만큼 반복해서 나열하기" 문제였음

## 배운 점
- `if arr[i]:` 처럼 숫자를 그냥 조건문에 넣으면, 0은 False, 0이 아닌 값은 True로 자동 판별됨
- 문제를 완전히 이해 못 해도, 예시 입출력을 보면서 일단 작은 로직부터 시도해보는 것도 방법 중 하나 (다만 나중엔 "왜 되는지" 다시 짚고 넘어가는 습관 들이기)
